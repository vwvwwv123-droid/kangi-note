# 채팅 기록 요약 — claude.ai 프로젝트 "조현우 한자앱"

claude.ai 프로젝트에서 진행한 대화(2026-10-15 ~ 10-16, "로그인 문제" 세션)의 결정·교훈을 Claude Code가 참고할 수 있게 정리한 것. 코드 자체는 저장소 `index.html`이 원본이다.

## 1. 시간순 작업 흐름
1. **로그인 실패 진단** — 원인은 Claude 아티팩트 링크가 외부 서버 호출을 막아 "이 기기 모드"로만 동작했기 때문. → GitHub Pages로 이전 결정.
2. **GitHub 계정·저장소 생성** (`vwvwwv123-droid/kangi-note`, 이름은 "kangi" 오타 그대로 유지) → Pages 활성화 → 정식 주소 확정.
3. **Claude GitHub App 설치** → Claude가 `main`에 직접 푸시. 수동 업로드 종료.
4. **Supabase 설정 정리** — Confirm email 끔, Site URL을 Pages 주소로. 첫 가입자가 자동 관리자.
5. **v18 비밀번호 찾기** — 재설정 메일 → `type=recovery` 감지 → 새 비밀번호 화면. 첫 배포에서 복구 화면 대신 로그인이 뜨는 버그: Supabase 라이브러리가 URL 해시를 먼저 지워서 감지 실패 → 페이지 로드 직후 `INIT_URL`에 보관하는 방식으로 수정. 첫 화면 항상 로그인 탭, 이메일 예시 `hyunwoo@gmail.com`.
6. **v20 PWA** — `manifest.json`, `icons/`(처음엔 생성 아이콘, 이후 사용자가 준 주황 고양이 사진 얼굴 크롭으로 교체), `sw.js`(index.html 네트워크 우선, 정적 파일 캐시 우선). 설치 앱과 브라우저 탭은 저장소가 분리되어 각각 로그인 필요.
7. **v21 복습 대기 개선** — 마지막 답(몰라요/애매/알아/쉬워/기록 없음) 칩 필터, 레벨별 묶음, "전체 복습하기"/"N#만 복습" 버튼. 카드에 `g`(마지막 답) 저장.
8. **FSRS 설명 선행** — 사용자가 알림 설계 전에 기존 FSRS 로직 설명을 요구 → 카드 필드(S/D/L/d/n/w), 채점 흐름, "복습할 것 = d ≤ now", 몰라요는 큐 3번째 재삽입 등을 정리하고 확인받음.
9. **v22 복습 알림** — Web Push + Edge Function `notify` + pg_cron. 규칙은 CLAUDE.md §5. VAPID 키 생성(비공개키는 저장소 밖), 키 포함 SQL은 `.gitignore`. Edge Secrets 4개를 사용자가 대시보드에 직접 입력.
10. **알림 함수 최적화** — 사용자가 무료 한도를 묻자, 초기 버전이 egress를 과하게 쓸 수 있어 수정본을 재배포하도록 전달.
11. **관리자 사용자 삭제** — 설계·SQL(`supabase/2026-10-16_admin_delete_user.sql`, 이메일 차단 트리거 포함)까지 만들었으나 사용자가 "이 기능은 나중에 하자" → UI 제거, SQL은 저장소에 보존(git `509a5d8`).
12. **v23 사용 설명 10장** — "자, 시작해볼까" 앞에 복습 대기·알림 설명 페이지(목록 형식) 추가.
13. **구조 설명** — GitHub=땅(파일·주소), Supabase=금고·집사(계정·기록·알림), PWA=현관, Claude=수리공 비유로 설명 → README "구조 개요"에 반영.

## 2. 사용자가 명시적으로 정한 것 (바꾸지 말 것)
- 몰라요 알림은 "떠난 시각 + 10분", 그 안에 들어오면 안 보냄.
- 복습 대기 ≥1이면 카카오톡 미읽음처럼 주황 배경 "N" 배지.
- 애매/알아/쉬워는 "N일 뒤 아침 8시"(같은 시각 아님). 몰라요는 시간 무관 10분.
- 밀린 카드는 최초 예정 알림 1회만, 추가는 매월 1일 08시 "밀린 한자 복습카드 N개"만.
- 문구는 Claude 추천안 채택하되 "강숙이가 먼저 와 있을게!" 류는 제외.
- 사용자 삭제 기능은 보류.
- "비밀번호를 찾기" → "비밀번호 찾기"로 가정 진행(사용자 이의 없음).

## 3. 사용자가 물었던 개념 질문과 답(재질문 대비)
- **마지막 접속 기준**: 로그인 시각이 아니라 앱이 화면에 떠 있던 마지막 순간. 활동 이벤트마다 + 30초 주기 갱신. 백그라운드에 열려만 있으면 멈춤(page visibility 기준).
- **몰라요 카드가 10분 뒤 어떻게 보이나**: `d`가 now+10분으로 저장되어 복습 목록에 들어감. 학습 중에는 큐 3번째 자리에 다시 나옴.
- **Supabase vs Firebase**: 둘 다 BaaS. Supabase는 Postgres+RLS 기반, 무료 플랜으로 충분.
- **무료 한도**: 전부 무료 구간(한도의 10% 미만). 수백 명 규모면 유료($25/월) 검토.

## 4. 작업 방법 교훈 (Claude Code에서도 그대로 적용)
- 단일 파일 5.5MB라 함수명 추측이 자주 빗나감 → **regex로 위치 출력 후** 치환.
- 치환은 항상 `assert s.count(old)==1` → 근접 중복 여러 번 잡아냄.
- 편집 후 인라인 `<script>` 전부 `new Function()`으로 문법 검사.
- 기능 검증은 Playwright 헤드리스(420×860)로 가입→닉네임→`grade()` 호출→스크린샷. 사용자에게 수동 테스트 요청은 마지막 수단.
- GitHub 연결: claude.ai에서는 `add_repo` → clone → 푸시. Claude Code에서는 로컬 clone + `gh`/git 인증으로 동일하게 푸시.
- GitHub 익명 조회는 rate limit에 걸릴 수 있음. 대시보드 메뉴 위치는 설명과 다를 수 있으므로 "안드로이드/아이폰", "크롬/사파리"를 먼저 묻고 하나만 안내함.
